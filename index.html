Reports Output Help
What each report option shows, why you would select it, and what appears in the output.




How Reports works. Scope + Filters determine the matching image population first. The report checkboxes do not change which images match; they choose which analysis blocks are calculated for that same population.


Matching image rows. Custom Reports also include one row per matching image with Image ID, filename, Batch, Director Reactions, Director Themes, PrimFusion, AI–Director agreement, Saved, and Flagged. These rows are the image-level evidence behind the selected report summaries.






Summary
Question it answers: How large and complete is the matching population?
SelectSummaryShowsimages · saved · flagged · aiCovered · directorCovered · incomplete
What the numbers mean: Images is the number of matching records. Saved and Flagged count those attributes. AI-covered counts records containing AI analysis data. Director-covered counts records containing Director analysis data. Incomplete counts matching records with no Director analysis record.
Use it when: you want the basic size, coverage, and status totals before examining distributions.
Example: “Of the 100 images matching these filters, how many have AI data, Director data, or are still untouched by Director?”


Director Reactions
Question it answers: Which Director Reactions occur in the matching population, and in what complete combinations?
SelectDirector ReactionsShowscounts · combinations
Counts totals each individual Director Reaction. Combinations totals complete Reaction sets, normalized into a consistent displayed order.
Use it when: you want Reaction frequencies or want to see which groups of Reactions tend to occur together.
Example: “How often is Funny selected, and what full Reaction combinations are most common in this Batch?”


Director Themes
Question it answers: Which Director Themes occur in the matching population, and in what complete combinations?
SelectDirector ThemesShowscounts · combinations
Counts totals each individual Director Theme. Combinations totals the complete Theme sets assigned to matching images.
Use it when: you want Theme frequencies or recurring Theme combinations.
Example: “Among images with Funny + Zazzly, how often does Exposure appear and which Theme trios recur?”


AI Theme Usage
Question it answers: Which Themes is AI selecting in this report population, where are they ranking, and how confident is AI?
SelectAI Theme UsageShowsscope images · theme results · missing results · custom rate · selections · % images · #1/#2/#3 · avg confidence
The visual table separates matrix Themes from Custom proposals, shows selection and rank frequencies, lists current Themes never selected in the population, and includes AI Theme prompt/model metadata when stored.
Use it when: you want to analyze AI Theme behavior for whatever Scope + Filters you chose.
Example: “Within these 80 filtered images, which Theme does AI choose most often, and is it usually its first-ranked choice?”


AI Description
Question it answers: What exact AI Description text existed for each matching image, and which Description artifact was actually paired with the current AI Theme decision?
SelectAI DescriptionShowscurrent Description · Description artifact/attempt · provider/model · prompt versions · generated time · Description history · same-attempt Theme linkage · preliminary Themes when preserved
Current reports the Description currently projected onto the Image Record. Theme-decision Description follows the current Theme artifact back to the Description artifact created in the same AI attempt, so a later standalone Description rerun does not rewrite the evidence behind an older Theme decision. History lists preserved Description artifacts for that image.
If Genreactrix cannot prove a same-attempt Description/Theme relationship, the report says so rather than assuming one.
Use it when: you need to audit whether final Themes faithfully used the Description that actually drove that Theme run.
Example: “Show the exact Description behind these Scary Theme selections, including the preliminary Themes that informed that Description and the provider/prompt metadata for the attempt.”


Reactions Info
Question it answers: What stored AI Reaction explanation or diagnostic information exists for the matching images?
SelectReactions InfoShowsimageId · stored reactionReasons or reactionDiagnostics
Only matching images that actually contain stored Reaction reasons or diagnostics appear in this block.
Use it when: you need image-by-image AI Reaction evidence rather than Reaction frequency counts.
Example: “Show me the stored AI Reaction explanations for the images that matched my disagreement filter.”


Themes Info
Question it answers: What stored AI Theme reasoning exists for the matching images?
SelectThemes InfoShowsimageId · stored genreReasons
Only matching images that contain stored Theme reasoning appear in this block.
Use it when: you want image-by-image Theme reasoning instead of Theme frequency statistics.
Example: “For these AI-only Reaction cases, what Theme reasoning did AI store for each image?”


PrimFusion
Question it answers: Which PrimFusion classifications occur most often in the matching population?
SelectPrimFusionShowscounts by PrimFusion label/ID
Reports counts the stored Director PrimFusion label or ID. When no labeled PrimFusion is stored, records with sufficient Director Reaction data may use the Reaction-derived fallback already used by the Reports engine.
Use it when: you want the distribution of PrimFusion classifications for the selected population.
Example: “Which PrimFusion occurs most often among images the Director marked Zazzly?”


AI–Director
Question it answers: How often do AI Reaction signals align with completed Director Reaction choices?
SelectAI–DirectorShows for each Reactioncomparable · agree · agreementRate · highAiDirectorNo
Comparable is the number of Director-complete matching records with a usable AI score for that Reaction. Agree counts cases where Director selected/not-selected matches AI’s 50% yes/no boundary. Agreement rate is Agree ÷ Comparable. highAiDirectorNo counts cases where Director did not select the Reaction but AI scored it at least 70%.
Use it when: you are studying where AI and Director classifications align or diverge.
Example: “For Funny, how many images were comparable, what percentage agreed, and how often was AI at 70%+ when Director said no?”


Sources
Question it answers: Where did the matching images come from?
SelectSourcesShowscount by source.type
Each matching record is counted under its stored source type; records without one are counted as unknown.
Use it when: you want to compare how much of the population came from each acquisition/source category.
Example: “How many of these matching images were local imports versus another stored source type?”


Workflow
Question it answers: Where are the matching records in the workflow, and do they carry key problem/retention states?
SelectWorkflowShowsstages · failed · recycled · missingSource
Stages counts the current stored workflow stage. Failed counts records with the failed attribute. Recycled counts records marked in Recycle Bin. Missing source counts records whose stored source reference is missing.
Use it when: you want operational status for the same research population.
Example: “Of the images matching this Reaction query, how many are Batched, failed, recycled, or missing their source?”


Matching Images
Question it answers: Which actual Image Records matched my Scope + Filters?
SelectMatching ImagesShowsfilename · workflow stage · Director completion · AI–Director agreement · Saved/Flagged
This is a lightweight result list. Reports does not load image or thumbnail data while rendering it. Tap any result card to open the existing Image Inspector for that canonical Image Record.
Use it when: you want to inspect the actual examples behind a query without making the report itself load image assets.
Example: “Show me the Image Records that matched Funny + Zazzly.”


Uncertain Images
Question it answers: Which matching images have recorded evidence that the Director opened/viewed AI while evaluating them?
SelectUncertain ImagesShowsfilename · uncertainty reason · AI–Director agreement
This view does not guess uncertainty from low scores. Current supported evidence is a recorded AI-view/SHOW AI history event or legacy Director data showing AI was visible at commit time.
Use it when: you want a review queue of classifications where AI was consulted.
Example: “Among this Batch, which images caused me to open AI before deciding?”


Difficult Images
Question it answers: Which matching images have explicit stored signs of classification difficulty?
SelectDifficult ImagesShowsfilename · Undo count · Redo count · changed-after-AI · manual flag · reasons
Current supported signals are recorded Undo, Redo, a prior Director classification that was changed after AI had been viewed, or a manual Review flag. The view reports the reason instead of assigning an invented difficulty score.
Use it when: you want examples worth revisiting for methodology, definition tuning, or error analysis.
Example: “Show me the filtered images where I undid a choice, changed an existing classification after viewing AI, or flagged the image for review.”


Productivity
Question it answers: What processing-rate information can the stored Director timestamps support for this population?
SelectProductivityShowsDirector-complete images · timestamped images · first/last completion · elapsed completion span · completion throughput · average completion interval
Genreactrix only calculates metrics supported by stored timestamps. If individual classification-start or duration evidence is absent, averageTimePerImageMinutes remains null rather than being invented.
Use it when: you want a bounded throughput audit for a session, Batch, date range, or other filtered population.
Example: “Across these timestamped completed images, what was the completion span and approximate completion rate?”


Research JSON / Research CSV
These are export buttons, not report checkboxes. They export the current report population in a research-oriented image-level structure.
SelectResearch JSONOrResearch CSVIncludesreport definition/results · source/workflow/timestamps · Director data · AI reaction scores/current AI data · PrimFusion · agreement · review signals
Research JSON preserves nested data and the report definition. Research CSV flattens one row per matching image and includes separate columns for the 14 canonical AI Reaction scores.
Use it when: you want data for external research analysis rather than a human-readable report snapshot.


AI Theme Usage · Latest Run
This is a dedicated report button, not a checkbox module. It automatically finds the newest AI analysis job in which the Themes component was enabled and restricts the report population to images belonging to that job.
SelectAI Theme Usage · Latest RunAutomatically useslatest AI Themes-enabled job · Summary · AI Theme Usage
It produces the specialized AI Theme Usage visual without requiring you to configure Scope or Filters first.
Use it when: you want the fastest audit of the most recent AI Theme run itself.
Example: “What did AI do with Themes in the latest Themes-enabled analysis run?”










Reports Filter Help
What each filter means and exactly what to select.




Operator rule. Has / equals means the complete condition written by that filter must be true. Does not have negates the complete condition; it does not merely negate one text box. Example: the inverse of Funny AND NOT Adorable is NOT(Funny AND NOT Adorable), which means Funny is missing OR Adorable is present. For numeric/comparison filters, records without the required usable AI score or AI–Director comparison remain excluded rather than becoming matches through negation.


Filter logic. All conditions (AND) requires every filter row to match. Any condition (OR) requires at least one filter row to match.






Director reaction
Find images where the Director selected one Reaction.
FilterDirector reactionValueFunnyOperatorHas / equals
Result: Director selected Funny.
If you choose Does not have: Leave the fields the same and change Operator to Does not have. Result: Director did not select Funny.


Director reaction combination
Find images where the Director selected every listed Reaction. Other Reactions may also be selected.
FilterDirector reaction combinationValueFunny, ZazzlyOperatorHas / equals
Result: both Funny and Zazzly are selected, regardless of any additional Director Reactions.
If you choose Does not have: Leave the fields the same and change Operator to Does not have. Result: the full combination is false — at least one of Funny or Zazzly is missing. It does not mean that both must be missing.


Director reaction without another
Find images where one Director Reaction is selected and another specific Reaction is not selected.
FilterDirector reaction without anotherReactionFunnyWithout reactionAdorableOperatorHas / equals
Meaning of Has / equals: the whole compound condition Funny AND NOT Adorable is true.
If you choose Does not have: Leave the fields the same and change Operator to Does not have. This negates the whole condition: NOT(Funny AND NOT Adorable). Result: Funny is missing OR Adorable is present.


Exact Director reaction set
Find images whose Director Reactions are exactly the listed set, with no additional Reactions.
FilterExact Director reaction setValueFunny, ZazzlyOperatorHas / equals
Result: Funny and Zazzly are selected and no other Director Reaction is selected.
If you choose Does not have: Leave the fields the same and change Operator to Does not have. Result: any Director Reaction set other than exactly Funny + Zazzly — a listed Reaction may be missing, an extra Reaction may be present, or both.

If you choose Does not have: Leave the fields the same and change Operator to Does not have. Result: Exposure is not in the Director Theme selections.


Exact Director theme set
Find images whose Director Themes are exactly the listed set, with no additional Themes.

Result: those three Themes are the complete Director Theme set.
If you choose Does not have: Leave the fields the same and change Operator to Does not have. Result: any Theme set other than exactly those three — a listed Theme may be missing, an extra Theme may be present, or both.
