# Emojeo — reusable-engine extraction baseline

Emojeo began as an independent clone of Genreactrix so its proven infrastructure can be generalized instead of rebuilt.

This checkpoint is deliberately **not yet an Emojeo feature build**. It starts separating reusable mechanisms from Genreactrix-specific semantics. See `ENGINE_EXTRACTION.md`.

The inherited Genreactrix release history is preserved in `GENREACTRIX_INHERITED_RELEASE_HISTORY.md`.
